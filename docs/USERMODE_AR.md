# واجهة وضع المستخدم في Fluxmax

هذه نسخة أولية من ABI لنواة x86-64 وليست POSIX أو Linux ABI.

## تشغيل البرنامج المضمّن

من صدفة النواة:

```text
run /bin/hello
```

يحاول الأمر تحميل ELF64 ثابت من VFS، وإنشاء فضاء عناوين خاص به، وتعيين مقاطع PT_LOAD ومكدس user، ثم إنشاء سياق Ring 3. البرنامج التجريبي المضمّن يستعمل `int 0x80` لطباعة رسالة ثم الخروج.

## الاستدعاءات

| رقم | الاسم | المعاملات |
|---:|---|---|
| 0 | `exit` | `status` في RDI |
| 1 | `write` | `fd` في RDI، عنوان البيانات RSI، الطول RDX؛ يدعم fd 1 و2 فقط |
| 2 | `getpid` | لا شيء |
| 3 | `yield` | لا شيء؛ نقطة جدولة عند العودة |
| 4 | `uptime` | لا شيء؛ يعيد ticks المؤقت |

رقم الاستدعاء في RAX. معاملات x86-64: RDI, RSI, RDX, R10, R8, R9. النتيجة في RAX، والسالب يشير إلى خطأ داخلي. بوابة `int 0x80` مهيأة بمستوى DPL3 في IDT.

## حدود وأمان

المحمّل يقبل static ET_EXEC x86-64 فقط، ويرفض ET_DYN/الربط الديناميكي. لا توجد حتى الآن مكتبة libc أو descriptors عامة أو fork/exec/wait أو signals أو demand paging/COW، والحماية لم تخضع لمراجعة أمنية. بناء ELF واختبار الخرائط داخل مصدر النواة لا يثبت نجاح تنفيذ Ring 3 قبل مرور فحص QEMU وإجراء اختبار تشغيل فعلي.
